## Reflection in Java

- **Reflection** in Java refers to examining information about classes, methods, fields, and other program elements at runtime.
- It allows a program to obtain information about its structure while the program is running.

## Exceptions, Assertions, and Logging

Exceptions, assertions, and logging are different mechanisms used while developing and running programs.

- **Exceptions** deal with situations where an error or unexpected condition occurs during program execution.
- **Assertions** are used to check assumptions about the program during development.
- **Logging** is used to record information about what is happening in a program, which can help in understanding and debugging its behaviour.

These concepts are related to identifying, checking, and understanding problems or behaviour in a program, but they serve different purposes.

## Generic Programming

- **Generic programming** allows classes and methods to work with different types while maintaining type safety.
- Generics are useful when the same program structure needs to work with different kinds of data.

## Collections

- A **collection** is used to store and manage a group of objects or values.
- Collections provide different ways of organizing and accessing multiple elements.

Examples discussed include:

- **List** – stores elements in an ordered collection and can contain duplicates.
- **Set** – stores unique elements.
- **Map** – stores elements as key-value pairs.
- **Queue** – generally processes elements in the order in which they are added.
- **Stack** – generally follows last-in-first-out behaviour.

## View

- A **view** is the visual or user-facing part of a GUI application.
- It contains the components that the user can see and interact with, such as buttons, text fields, lists, sliders, and other controls.

## Event Handling

- **Event handling** is the process of responding to actions performed by the user or generated by the application.
- Examples include button clicks, mouse actions, keyboard input, and changes in control values.
- An event handler contains the code that specifies what should happen when a particular event occurs.

### Event Handling and GUI

GUI applications depend on event handling because the user interacts with visual components.

The basic process is:

```text
User action
    ↓
Event occurs
    ↓
Event handler detects the event
    ↓
Corresponding action is performed
```

For example, clicking a button generates an event, and the event handler can execute a particular operation in response.

## Graphics vs Console

### Graphics / GUI

- Provides a visual interface for displaying and interacting with objects.
- Users interact with components such as buttons, sliders, checkboxes, and other controls.

### Console

- Provides a text-based interface.
- Input and output are generally represented as text in the terminal or command line.

The main difference is that a GUI provides visual and interactive components, while the console primarily uses text.

## Event Hierarchy

- Events in a GUI application can be organized in a hierarchy.
- Different events can have different types and properties.
- Understanding the event hierarchy helps in identifying the appropriate event and event handler for a GUI component.

## Layouts

Layouts determine how GUI components are arranged inside a window or container.

### Border Layout

- Arranges components using regions of a container.
- The common regions are:
  - North
  - South
  - East
  - West
  - Center

### Grid Layout

- Arranges components in a grid of **rows and columns**.
- Each component is placed into a cell of the grid.
- It is useful when components need to be arranged in a regular structure.

Example:

```text
┌─────────┬─────────┬─────────┐
│ Button  │ Button  │ Button  │
├─────────┼─────────┼─────────┤
│ Button  │ Button  │ Button  │
└─────────┴─────────┴─────────┘
```

## Checkboxes and Radio Buttons

Both are GUI controls used for selecting options, but they behave differently.

### Checkbox

- Allows multiple options to be selected independently.
- More than one checkbox can be selected at the same time.

### Radio Button

- Used when the user should select one option from a group of mutually exclusive choices.
- Selecting one option generally means another option in the same group is deselected.

## Slider

- A **slider** is a GUI control used to select a value from a range.
- The user moves a handle along a track to choose the required value.
- Sliders are useful for choosing **continuous values**, such as size, thickness, brightness, volume, or zoom level.
- The slider can generate an event when its value changes, allowing the program to respond to the new value.

## Dialog Boxes

- A **dialog box** is a small GUI window used to communicate with the user.
- It can be used to:
  - Display information
  - Show warnings or errors
  - Ask for confirmation
  - Request input
- Dialog boxes are useful when the application needs the user's attention or a specific response.
