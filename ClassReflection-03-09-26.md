## Group 4 – ASCII Tree

- The project involves creating an **ASCII tree** by printing the tree using ASCII characters.
- `print` is used to display the output on the **console**.
- A tree can be represented by creating a logic that prints the required characters **line by line**.
- Important characters for drawing a vertical tree include:
  - Vertical line
  - Horizontal dash
- **Printing and drawing** are different approaches to representing a structure.
- The **terminal/console** is a text-based environment for displaying such output.
- A remote computer can be accessed without a GUI using **SSH**.
- Text-based environments can provide a robust computing environment.
- **SSH and Node** were discussed in the context of working with remote or text-based environments.
- While creating an ASCII tree, the spacing and placement of characters need to be handled carefully.
- Problems such as **gaps and horizontal scrolling** can occur if the tree is not represented correctly.

- The project involves creating a **splash screen using FXML**.

## Group 7 – Tree of Objects

- The project involves creating a **tree of objects** with support for editing each object.
- An **object** represents an entity that can be handled within the program.
- The project involves working with **files and folders**.
- **Serialization** was discussed as a way of saving objects.
- Objects stored in memory can be saved through serialization so that their state can be preserved.

## Group 8 – Composite Processor

- The project involves a **composite processor** for tracking multiple jobs.
- The processor should provide support for **cancellation**.
- **Thread management** and **thread cancellation** were discussed.
- Cancellation can be useful when a program needs to stop a thread while still giving it time to **wrap up its work properly**.
